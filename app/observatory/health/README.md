# Health observatory

Пакет `health` - наблюдатель адаптивного ядра. Он собирает пассивные улики по трафику outbound, проверяет их пробами, выбирает путь для балансировщика `leastCost` и принимает наборы outbound от провайдера. Хост управляет им командами и забирает Status, события и отчёт.

Справочник лежит в [`docs/adaptive`](../../../docs/adaptive/README.md): конфиг, протокол провайдера, команды хоста и выходные данные.
